Punkte-Speicher

Die Spieler und Punktestände liegen als Datei im GitHub-Repo. Zum Speichern braucht dieser Browser einmalig einen Schlüssel. Am einfachsten öffnest du den Einladungslink – dann passiert alles automatisch. Alternativ den Schlüssel hier einfügen:

Wie bekomme ich einen Schlüssel? (nur für den Repo-Besitzer)
  1. Hier einen neuen Token erstellen (Name, Ablauf und Berechtigung sind schon vorausgefüllt).
  2. Bei Repository access „Only select repositories“ wählen und nur auswählen.
  3. Prüfen, dass unter Permissions → Contents „Read and write“ steht, dann Generate token.
  4. Token kopieren, oben einfügen, speichern – danach den Einladungslink an deine Freunde schicken.

Der Einladungslink enthält den Schlüssel. Wer ihn öffnet, kann Punkte speichern – schick ihn also nur an Freunde.
